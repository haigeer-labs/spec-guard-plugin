首次在独立 `CODEX_HOME` 中运行 `evals/codex-plugin-smoke.sh` 时，脚本返回退出码 `2`（环境未就绪），随后 `codex login status` 明确返回 `Not logged in`。该结果被正确地记录为隔离配置缺少登录态，而非产品故障；后续已在已登录宿主中完成运行时验证。

已通过的实际验证命令为：

```bash
/bin/bash evals/codex-plugin-smoke.sh \
  --plugin-id spec-guard@spec-guard-marketplace \
  --expected-source /Users/vilin/.codex/.tmp/marketplaces/spec-guard-marketplace/plugins/spec-guard
```

通过条件是 hook 输出包含“当前阶段:”。本次命令满足该条件，故 `v0.11.1` 的宿主运行时 hook 已验证。

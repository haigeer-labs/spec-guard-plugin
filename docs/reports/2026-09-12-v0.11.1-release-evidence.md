## 未闭合项：隔离宿主 hook 验证

`evals/codex-plugin-smoke.sh` 在上述独立 `CODEX_HOME` 中返回退出码 `2`（环境未就绪），随后 `codex login status` 明确返回 `Not logged in`。这说明此隔离测试配置没有 Codex 登录态；它不是 hook 运行失败的证据，也不应被记为产品 bug。

要取得完整的宿主运行时证据，应在已登录、并已在 `/hooks` 审核信任插件的 Codex 会话中执行：

```bash
/bin/bash evals/codex-plugin-smoke.sh \
  --plugin-id spec-guard@spec-guard-marketplace \
  --expected-source <安装来源目录>
```

该命令应以 hook 输出包含“当前阶段:”为通过条件。没有该证据前，本版本的运行时 hook 状态应保持“待验证”，而非标记为失败。
